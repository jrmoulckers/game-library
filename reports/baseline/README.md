# Sanitized baselines

These reports contain aggregate counts under symbolic root IDs only. Exact
relative paths, file hashes, identity proposals, duplicate groups, and dry-run
actions are retained outside the repository for explicit migration review.

- `desktop-2026-08-09.json` was generated by `gamelib inventory scan` from the
  canonical catalog, desktop Steam export, Playnite library media, and Playnite
  ExtraMetadata surfaces. It inventories 1,218 files / 1,239,252,960 bytes.
- Its 72 validation issues are extension/content mismatches: 47 `.jpg` files
  contain PNG bytes, 24 `.png` files contain WebP bytes, and one `.ico` file
  contains BMP bytes. They are reported for later normalization decisions and
  are not changed or quarantined automatically.
- `topology-2026-08-08.json` preserves aggregate results from the preceding
  read-only desktop, Steam Deck, CT replica, Playnite, and RetroDECK inventory.

Regenerating a baseline is read-only with respect to source roots. Do not commit
the private inventory or exact plan outputs.

Committed artifacts here carry no environment residue — no absolute user paths,
home directories, or account identifiers
([`ENG-SEC-001`](https://github.com/jrmoulckers/engineering/blob/v0.2.0/principles/assurance/security-and-privacy.md#secret-lifecycle)).
That rule is not left as prose: CI fails the build when residue reappears in this
directory, which is the executable form required by
[`ENG-TEST-010`](https://github.com/jrmoulckers/engineering/blob/v0.2.0/principles/assurance/testing.md#executable-procedures).
